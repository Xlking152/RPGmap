# Movement System 模块化整理

- 新增统一 `src/movement/` 子系统，集中管理 Session、状态机、A* 分段路径、吸附、距离计价、幽灵预览、输入控制与渲染。
- 应用入口改为单一 `createMovementSystem()`；旧 `src/engine/*` 与 `src/tools/*` 移动相关路径仅保留兼容导出，避免重复实现继续扩散。
- 角色被选择或直接拖动时，会依据当前地图米/像素尺度自动选择 `5 / 10 / 20 / 50 / 100 m` 初始移动档位。
- 路径规划期间滚轮切换移动档位并实时重算当前尾段；已确认 waypoint 保持原坐标，不会随档位变化跳动。
- 同一移动档位同时驱动当前控制点吸附与分段移动计价；真实 A* 路径长度、碰撞和动态障碍精度保持不变。
- 顶部“移动角色”点击模式与直接 Token Drag 统一进入同一个 MovementController，后续速度、困难地形、多角色和飞行模式可在同一接口继续扩展。
- 新增 3 项移动吸附/自动档位测试；完整自动化测试为 78/78 通过。
