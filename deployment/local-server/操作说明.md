# RPGmap V1.4.3 操作说明

本文面向解压后实际运行 RPGmap 的 GM / Player。项目架构、开发说明和整体路线请看 GitHub 仓库根目录 `README.md`。

## 1. 发布包目录

```text
RPGmap-v1.4.3/
├─ 启动 RPGmap.bat       Windows 唯一启动入口
├─ 操作说明.md
├─ app/                  RPGmap 前端程序
├─ launcher/             Web Launcher / GM 本机控制台
├─ server/               Multiplayer Server 内部程序
├─ world/                当前 World / Campaign 持久数据
│  ├─ state.json         运行后生成
│  ├─ users.json         有正式 User 后生成
│  ├─ uploads/
│  └─ backups/
├─ maps/                 真正 Map / Scene 资源库
├─ tools/                cloudflared / 未来 Portable Node 等内部工具
├─ docs/
└─ VERSION.json
```

普通 Windows 用户只需要记住：

```text
启动 RPGmap.bat
```

V1.4.3 不再提供 Native Launcher EXE，也不再暴露多个启动 BAT。

## 2. 启动 RPGmap

双击：

```text
启动 RPGmap.bat
```

BAT 会：

1. 优先查找 `tools/node/node.exe`；
2. 其次查找 RPGmap 根目录 `node.exe`；
3. 再查找系统 PATH 中的 `node.exe`；
4. 启动 `launcher/launcher.mjs`；
5. Launcher 自动打开浏览器 GM Control Center。

当前要求：

```text
Node.js ^20.19.0 或 >=22.12.0
```

如果没有检测到 Node.js，BAT 会直接显示错误并暂停，不会静默退出。

Launcher runtime 输出保存在：

```text
launcher-startup.log
```

如果浏览器没有自动打开，可优先检查这个文件。

## 3. Launcher 地址与动态端口

Launcher 只监听本机：

```text
127.0.0.1
```

首选端口：

```text
29999
```

如果被占用，会自动尝试：

```text
29998 → 29997 → 29996 → 29995
```

如果仍然全部被占用，则让 Windows 自动分配一个当前空闲端口。

Launcher 会自己打开最终地址，用户不需要手动改端口，也不需要强制关闭占用端口的其他程序。

Game Server 默认仍使用：

```text
30000
```

## 4. Launcher 页面能做什么

Launcher 集中显示：

- RPGmap Server 状态；
- 本机地址；
- 局域网地址；
- Internet Public URL；
- Join Code / 房间号；
- GM Secret；
- Player 邀请文本；
- World / Maps 路径；
- 在线 User / Player；
- Server / Tunnel 运行日志。

所有 GM 后台操作都放在网页中，BAT 只负责启动。

## 5. 启动本机 / 局域网

在 Launcher 点击：

```text
启动本机 / 局域网
```

Launcher 自动：

1. 生成本次 Session 的 Join Code；
2. 生成 GM Secret；
3. 启动 Multiplayer Server；
4. 建立隐藏的 Launcher GM Admin Session；
5. 显示本机 / LAN 地址；
6. 加载 User / Ownership 后台。

GM 点击“打开 RPGmap”进入游戏。

同一 LAN 的 Player 使用 Launcher 中显示的局域网地址和 Join Code。

## 6. 启动互联网联机

在 Launcher 点击：

```text
启动互联网联机
```

Launcher 自动：

1. 检测 `cloudflared`；
2. 优先使用 `tools/cloudflared.exe`；
3. Windows 首次缺失时下载官方 `cloudflared` 到 RPGmap 包内 `tools/`；
4. 创建 Cloudflare Quick Tunnel；
5. 使用 HTTP/2 over TCP；
6. 生成 Join Code 和 GM Secret；
7. 启动 RPGmap Server；
8. 显示 Public URL；
9. 生成玩家邀请文本。

给 Player 发送 Launcher 中的“玩家邀请”即可，例如：

```text
RPGmap 房间

地址：https://xxxx.trycloudflare.com
房间号：381624
```

**不要把 GM Secret 发给 Player。**

## 7. GM Secret

GM Secret 位于单独的“GM 安全区”，默认隐藏，可以显示 / 复制。

“复制玩家邀请信息”永远不会包含 GM Secret。

GM Secret 是本次 Server Session 的 GM 身份凭证，停止 Server 后重新启动会生成新的值。

## 8. Launcher 后台 User 管理

Launcher 不直接修改 `world/users.json`。

它会在本机建立一个隐藏 GM WebSocket Session，通过 Multiplayer Server 已有权限协议执行管理操作，因此 Launcher 和游戏内“联机 / Users”面板使用同一套 Server 逻辑。

Launcher 可以：

- 查看正式 Player Users；
- 查看在线 / 离线状态；
- 查看待批准 Player；
- 批准首次加入 Player；
- 预创建 User；
- 分配默认 Actor；
- 设置 `NONE / OBSERVER / OWNER`；
- 重发 Player Key；
- 删除 User；
- 查看 Actor 列表。

Server 最终写入：

```text
world/users.json
```

## 9. Player User 创建

### Player 先申请

1. Player 打开 RPGmap 地址。
2. 选择 Player，输入 Join Code。
3. 第一次加入后成为 pending。
4. GM 在 Launcher 的“待批准玩家”中看到该 Player。
5. GM 选择默认 Actor 并批准。
6. Server 创建 Persistent User。
7. Player 获得对应角色权限。

### GM 预创建

Launcher 可以在开团前预创建 Player User，并生成 Player Key。该 Key 应只私下发送给对应玩家。

## 10. Player Key

Quick Tunnel 重启后公网域名通常会变化，因此 RPGmap 同时使用：

- Browser Auth Token：同一网址自动重连；
- Player Key：新 Quick Tunnel URL 恢复同一个 Persistent User。

Launcher 可点击“重发 Player Key”。新 Key 会使旧 Player Key 和旧浏览器身份失效。

Server 只保存凭证哈希，不保存明文 Key / Token。

## 11. Actor Ownership

- `NONE`：无控制权；
- `OBSERVER`：观察 / 查看；
- `OWNER`：可操控 Actor。

每个 Player 可以有一个默认 Actor，以及多个 OWNER / OBSERVER Actor。默认 Actor 必须是 OWNER。

GM 对全部 Actor 隐式拥有完整权限。

## 12. Combat Turn Lock

Combat active 后，Player 即使拥有多个 OWNER Actor，也只能操控当前 Turn 对应的 Actor。

GM 负责 Combatant、Initiative、排序、开始 / 结束 Combat 和 Round / Turn 推进。

## 13. World / Maps

长期原则：

- `app/` = 程序是什么；
- `maps/` = Map / Scene 本身是什么；
- `world/` = 这一场游戏里发生了什么。

### world/

保存 User / Ownership、Actor / Token、Combat、Chat、地图实例状态、上传和备份。

### maps/

预留给真正地图系统：背景层、建筑、墙体、可破坏对象、Collision / Navigation、环境特效、损坏 / 摧毁变体等。

## 14. Launcher 未来功能入口

Launcher 首页已预留三个模块，但当前按钮保持禁用：

- `World Manager`：World 选择 / 创建 / 复制 / 归档 / 启动；
- `Scene Manager`：Map Registry / MapPackage / Scene 切换；
- `Backup Center`：Snapshot / 自动备份 / 恢复 / 导入导出。

## 15. 备份与升级

最重要的备份对象：

```text
world/
```

如果有自定义地图，再同时备份：

```text
maps/
```

升级程序时不要覆盖自己的 `world/` 与 `maps/`。

RPGmap 默认不会把 World / User 数据写入 AppData 或其他隐藏用户目录。

## 16. 旧版本迁移

新 `world/` 文件不存在时继续兼容：

```text
V1.4.1 Candidate
map/world.json  -> world/state.json
map/users.json  -> world/users.json

更旧版本
data/worlds/default/world.json  -> world/state.json
data/worlds/default/access.json -> world/users.json
```

旧文件不会自动删除。

## 17. 关闭

在 Launcher 点击“停止服务器”只停止当前 Game Server / Tunnel，Launcher 页面仍保持打开。

点击“关闭 Launcher”会停止 Game Server、Tunnel 和 Launcher 后台。

## 18. 常见问题

### 双击 BAT 后没有浏览器页面

查看：

```text
launcher-startup.log
```

也可以在 RPGmap 根目录手动执行：

```bat
node launcher\launcher.mjs
```

### 29999 已被占用

无需处理。Launcher 会自动改用其他 loopback 端口。

### cloudflared.exe 放哪里

推荐：

```text
tools/cloudflared.exe
```

没有时 Internet 模式可以自动下载。

## 19. 常用游戏操作

- Token 单选：左键
- 框选：空白地图左拖
- Shift：追加选择
- Alt：移除选择
- Token 移动：直接拖动
- Waypoint：Ctrl/Cmd + 点击或 `F`
- Enter：确认移动
- Esc：取消
- Ruler：`R`
- 从角色测距：`Shift + R`
- 切换 Form：`V`
