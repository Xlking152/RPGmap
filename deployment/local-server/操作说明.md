# RPGmap V1.4.3 操作说明

## 1. 启动方式

Windows 用户只需要双击：

```text
RPGmap.bat
```

启动后会保留一个 **RPGmap Runtime PowerShell 窗口**，同时浏览器自动打开 Web Launcher。

PowerShell 窗口用于查看运行信息，浏览器用于实际 GM 操作。

## 2. PowerShell Runtime 窗口

该窗口应保持运行，可以最小化。

它会：

- 查找 Node.js；
- 将包根目录 `maps/` 挂载到 `app/maps` 运行时路径；
- 启动 Web Launcher；
- 显示 Launcher 地址；
- 显示 Server 启动 / 停止日志；
- 显示 Local URL；
- 显示 LAN / Network URL；
- 显示 Internet Public URL；
- 显示 Join Code / 房间号；
- 显示 GM Secret；
- 显示 World / Maps 路径；
- 显示 Build / READY；
- 显示 Cloudflare Tunnel 日志。

Server 启动完成后，会看到类似：

```text
============================================================
 RPGmap Multiplayer Server  |  1.4.3
============================================================
 Local      : http://127.0.0.1:30000
 Network    : http://192.168.x.x:30000
 Public URL : https://xxxx.trycloudflare.com
 JoinCode   : 381624
 GMSecret   : ABCD1234EFGH5678
 Status     : READY
============================================================
```

因此即使浏览器页面暂时关闭，也可以从 Runtime 窗口重新查看连接信息。

## 3. Web Launcher

Web Launcher 负责所有交互：

- 启动 / 停止本机、LAN、Internet Server；
- 查看和复制 Local / LAN / Public URL；
- 查看 Join Code；
- 显示 / 隐藏 / 复制 GM Secret；
- 复制 Player Invite；
- 查看 Server / Tunnel 日志；
- pending Player approve；
- User create / update / delete；
- Default Actor；
- NONE / OBSERVER / OWNER；
- Player Key rotation。

Launcher 不直接修改 `world/users.json`，而是通过隐藏 GM WebSocket Session 使用 Server 权限逻辑。

## 4. Launcher 动态端口

Launcher 只绑定 `127.0.0.1`。

默认优先：

```text
29999
```

被占用后自动尝试：

```text
29998 → 29997 → 29996 → 29995
```

仍被占用时由 Windows 自动分配空闲端口。

无需强制关闭占用 29999 的其他程序，浏览器会自动打开正确地址。

## 5. Node.js

当前要求：

```text
Node.js ^20.19.0 或 >=22.12.0
```

Runtime 查找顺序：

```text
tools/node/node.exe
→ 根目录 node.exe
→ 系统 PATH node.exe
```

## 6. 本机 / 局域网联机

在 Web Launcher 点击：

```text
启动本机 / 局域网
```

Launcher 会生成 Join Code / GM Secret，启动 Game Server，并显示 Local / LAN URL。

## 7. Internet 联机

在 Web Launcher 点击：

```text
启动互联网联机
```

Launcher 会：

1. 查找 `tools/cloudflared.exe`；
2. 未找到时尝试自动下载官方 Windows 版本到 `tools/`；
3. 创建 Cloudflare Quick Tunnel；
4. 使用 HTTP/2 over TCP；
5. 启动 Game Server；
6. 显示 Public URL / Join Code / GM Secret；
7. 生成 Player Invite。

Player Invite 不包含 GM Secret。

## 9. app / maps / world 的区别

### app/

`app/` 是程序前端，只保存 RPGmap 引擎、UI 和构建后的 JavaScript/CSS。

**V1.4.3 默认兰州地图不再作为地图数据烘焙进 app。**

### maps/

`maps/` 是真正的 Runtime Map Library。默认地图为：

```text
maps/northern-song-lanzhou-1104/
```

其中：

```text
map.json    地图定义、SVG、features、Navigation、破坏规则等
assets/     地图专用 WebP 资源
```

地图注册表：

```text
maps/index.json
```

PowerShell Runtime 启动时会建立：

```text
app/maps  ->  根目录 maps/
```

这是 Windows Junction（目录联接），不是把地图复制一份。因此真正的数据仍然只在根 `maps/` 中。

如果你打开发布包后发现 `maps/` 只有 README、没有 `index.json` 和地图目录，说明拿到的是较早的 V1.4.3 Candidate 包，需要换成新的外置 MapPackage 构建。

### world/

`world/` 只保存当前 Campaign 的**可变运行状态**，不是地图模板。

新下载的干净发布包不会附送一场假的 Campaign，所以初次解压时下面两个文件可能不存在：

```text
world/state.json
world/users.json
```

这是正常的。

它们会在当前 World / User 数据首次持久化，或者从旧版数据迁移后产生。

因此：

```text
maps/  = 地图原本是什么
world/ = 这场游戏把地图、角色、战斗变成了什么状态
```

例如建筑模型、墙体几何、可破坏模板属于 `maps/`；某场跑团里“东墙已坍塌、建筑正在燃烧”属于 `world/state.json`。

## 10. 备份

至少备份：

```text
world/
```

如果使用或修改了自定义地图，同时备份：

```text
maps/
```

程序升级时 `app/` 可以整体替换，但不要随意覆盖自己的 `world/` 和 `maps/`。

## 11. User / Ownership

Player 首次加入可进入 pending，由 GM approve 后成为 Persistent User。

权限：

- NONE；
- OBSERVER；
- OWNER。

默认 Actor 必须是 OWNER。Combat active 时 Player 只能操控当前 Turn 对应的 OWNER Actor。

## 12. 未来模块

Launcher 已预留但暂未启用：

- World Manager；
- Scene Manager；
- Backup Center。

`maps/index.json` 已经作为未来 Scene Manager / Map Registry 的基础边界。

## 13. 关闭

点击 Web Launcher 的“停止服务器”：只停止 Game Server / Tunnel。

点击“关闭 Launcher”：结束 Launcher Node Runtime，PowerShell 窗口随后自动结束。

## 14. Troubleshooting

### 双击 RPGmap.bat 后没有网页

直接看 PowerShell Runtime 窗口中的错误。

也可以手动运行：

```bat
node launcher\launcher.mjs
```

### 29999 被占用

无需处理，Launcher 会自动换端口。

### maps/ 是空的

新的正确 V1.4.3 测试包应至少存在：

```text
maps/index.json
maps/northern-song-lanzhou-1104/map.json
maps/northern-song-lanzhou-1104/assets/
```

如果没有，说明是较早 Candidate 包。

### world/ 没有 state.json / users.json

新 World 尚未产生可持久化状态时属于正常情况，不需要手工复制地图进去。

### cloudflared.exe 放哪里

推荐：

```text
tools/cloudflared.exe
```

更多联机细节见 `docs/MULTIPLAYER-GUIDE.md`。
