# RPGmap V1.4.3 操作说明

本文面向解压后实际运行 RPGmap 的 GM / Player。项目架构、开发说明和整体路线请看 GitHub 仓库根目录 `README.md`。

## 1. 发布包目录

```text
RPGmap-v1.4.3/
├─ RPGmap.bat             Windows 唯一启动入口
├─ 操作说明.md
├─ app/                   RPGmap 前端程序
├─ launcher/              Web Launcher / GM 本机控制台
├─ server/                Multiplayer Server 内部程序
├─ world/                 当前 World / Campaign 持久数据
│  ├─ state.json
│  ├─ users.json
│  ├─ uploads/
│  └─ backups/
├─ maps/                  Map / Scene 资源库
├─ tools/                 cloudflared / 未来 Portable Node
├─ docs/
└─ VERSION.json
```

Windows 用户只需要双击：

```text
RPGmap.bat
```

V1.4.3 不再提供 Native Launcher EXE，也不再暴露多个启动 BAT。

## 2. 启动 RPGmap

`RPGmap.bat` 会依次查找：

1. `tools/node/node.exe`；
2. 根目录 `node.exe`；
3. 系统 PATH 中的 `node.exe`。

然后直接运行：

```text
launcher/launcher.mjs
```

当前要求：

```text
Node.js ^20.19.0 或 >=22.12.0
```

BAT 窗口是 Launcher Runtime，请保持它运行；可以直接最小化。真正的 GM 控制、日志和 User 管理都在浏览器 Launcher 页面中。

如果 Node/Launcher 启动失败，BAT 窗口会直接显示错误，不会静默退出。

启动基本信息同时写入：

```text
launcher-startup.log
```

## 3. Launcher 动态端口

Launcher 只监听本机 `127.0.0.1`。

首选：

```text
29999
```

冲突时自动尝试：

```text
29998 → 29997 → 29996 → 29995
```

仍然不可用时，由 Windows 自动分配空闲 loopback 端口。浏览器会自动打开最终地址。

因此不需要关闭占用 29999 的其他软件。

Game Server 默认仍使用：

```text
30000
```

## 4. Launcher 页面

Launcher 集中显示：

- Server 状态；
- 本机地址；
- 局域网地址；
- Internet Public URL；
- Join Code / 房间号；
- GM Secret；
- Player Invite；
- World / Maps 路径；
- 在线 User / Player；
- Server / Tunnel 日志。

## 5. 本机 / 局域网

点击：

```text
启动本机 / 局域网
```

Launcher 自动生成 Join Code / GM Secret、启动 Server、建立隐藏 GM Admin Session 并显示 Local / LAN 地址。

## 6. Internet 联机

点击：

```text
启动互联网联机
```

Launcher 自动：

1. 检测 cloudflared；
2. 优先使用 `tools/cloudflared.exe`；
3. Windows 缺失时下载官方版本到 `tools/`；
4. 创建 Cloudflare Quick Tunnel；
5. 使用 HTTP/2 over TCP；
6. 生成 Join Code / GM Secret；
7. 启动 Server；
8. 显示 Public URL；
9. 生成玩家邀请。

玩家邀请示例：

```text
RPGmap 房间

地址：https://xxxx.trycloudflare.com
房间号：381624
```

不要把 GM Secret 发给 Player。

## 7. GM Secret

GM Secret 位于单独安全区，默认隐藏，可显示 / 复制。“复制玩家邀请”永远不会包含 GM Secret。

## 8. User 管理

Launcher 不直接修改 `world/users.json`，而是建立隐藏 GM WebSocket Session，通过 Server 权限协议执行：

- pending Player approve；
- 预创建 User；
- Default Actor；
- NONE / OBSERVER / OWNER；
- Player Key rotation；
- delete User；
- 在线状态 / Actor catalog。

Server 最终负责写入：

```text
world/users.json
```

## 9. Player Key

Quick Tunnel 域名变化时：

- Browser Auth Token 用于同一网址自动重连；
- Player Key 用于新网址恢复同一个 Persistent User。

重发 Player Key 后，旧 Player Key 和旧浏览器身份失效。

## 10. Ownership / Combat

- `NONE`：无控制权；
- `OBSERVER`：观察 / 查看；
- `OWNER`：可操控 Actor。

默认 Actor 必须是 OWNER。GM 对全部 Actor 隐式拥有完整权限。

Combat active 后，Player 即使拥有多个 OWNER Actor，也只能操控当前 Turn 对应 Actor。

## 11. World / Maps

长期原则：

- `app/` = 程序是什么；
- `maps/` = Map / Scene 本身是什么；
- `world/` = 当前游戏发生了什么。

至少备份：

```text
world/
```

有自定义地图时同时备份：

```text
maps/
```

## 12. 未来功能入口

Launcher 首页已预留但暂未启用：

- World Manager；
- Scene Manager；
- Backup Center。

## 13. 旧版本迁移

```text
map/world.json  -> world/state.json
map/users.json  -> world/users.json

data/worlds/default/world.json  -> world/state.json
data/worlds/default/access.json -> world/users.json
```

旧文件不会自动删除。

## 14. 关闭

在网页 Launcher 点击“停止服务器”只停止 Game Server / Tunnel。

点击“关闭 Launcher”后 Node Runtime 结束，随后 BAT 窗口自然关闭。

## 15. Troubleshooting

### BAT 双击后没有网页

先看 BAT 窗口中的错误；也可以手动执行：

```bat
node launcher\launcher.mjs
```

### 29999 已被占用

无需处理。Launcher 自动选择其他本机端口。

### cloudflared.exe 放哪里

推荐：

```text
tools/cloudflared.exe
```

没有时 Internet 模式可以自动下载。

更多联机细节见：

```text
docs/MULTIPLAYER-GUIDE.md
```
