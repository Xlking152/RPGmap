# RPGmap V1.4.3 操作说明

本文面向解压后实际运行 RPGmap 的 GM / Player。项目架构、开发说明和整体路线请看 GitHub 仓库根目录 `README.md`。

## 1. 发布包目录

```text
RPGmap-v1.4.3/
├─ 启动 RPGmap.bat       Windows 唯一启动入口
├─ 操作说明.md
├─ app/                  RPGmap 前端程序
├─ launcher/             Launcher / GM 本机控制台
├─ server/               Multiplayer Server 内部程序
├─ world/                当前 World / Campaign 持久数据
│  ├─ state.json         运行后生成
│  ├─ users.json         有正式 User 后生成
│  ├─ uploads/
│  └─ backups/
├─ maps/                 真正的 Map / Scene 资源库
├─ docs/
└─ VERSION.json
```

对普通 Windows 用户，根目录只需要记住：

```text
启动 RPGmap.bat
```

V1.4.3 不再把 `start-rpgmap.bat`、`start-rpgmap-internet.bat`、`setup-cloudflared.bat`、`run-rpgmap-public-server.bat` 等多个入口暴露在发布包根目录。

## 2. RPGmap Launcher

双击：

```text
启动 RPGmap.bat
```

浏览器会自动打开本机 Launcher：

```text
http://127.0.0.1:29999
```

Launcher 只监听 `127.0.0.1`，用于 GM 本机控制，不会被 Cloudflare Quick Tunnel 暴露给远程玩家。

Launcher 集中显示：

- RPGmap Server 状态；
- 本机地址；
- 局域网地址；
- Internet Public URL；
- Join Code / 房间号；
- GM Secret；
- Player 邀请文本；
- World / Maps 路径；
- 在线 User / Player；
- 运行日志。

## 3. 启动本机 / 局域网

在 Launcher 点击：

```text
启动本机 / 局域网
```

Launcher 自动：

1. 生成本次 Session 的 Join Code；
2. 生成 GM Secret；
3. 启动 Multiplayer Server；
4. 建立隐藏的 Launcher GM Admin Session；
5. 显示本机 / LAN 地址；
6. 加载 User / Ownership 后台。

GM 点击“打开 RPGmap”进入游戏。

同一 LAN 的 Player 使用 Launcher 中显示的局域网地址和 Join Code。

## 4. 启动互联网联机

在 Launcher 点击：

```text
启动互联网联机
```

Launcher 自动完成：

1. 检测 `cloudflared`；
2. Windows 首次缺失时下载官方 `cloudflared` 到 RPGmap 包内 `tools/`；
3. 创建 Cloudflare Quick Tunnel；
4. 使用 HTTP/2 over TCP；
5. 生成 Join Code 和 GM Secret；
6. 启动 RPGmap Server；
7. 显示 Public URL；
8. 生成可直接复制的玩家邀请文本。

给 Player 发送 Launcher 中的“玩家邀请”即可，例如：

```text
RPGmap 房间

地址：https://xxxx.trycloudflare.com
房间号：381624
```

**不要把 GM Secret 发给 Player。**

## 5. GM Secret

Launcher 将 GM Secret 单独放在“GM 安全区”，默认隐藏。

可以：

- 显示 / 隐藏；
- 单独复制。

“复制玩家邀请信息”永远不会包含 GM Secret。

GM Secret 是本次 Server Session 的 GM 身份凭证，停止 Server 后重新启动会生成新的值。

## 6. Launcher 后台 User 管理

V1.4.3 的 Launcher 不直接修改 `world/users.json`。

它会在本机建立一个隐藏 GM WebSocket Session，通过 Multiplayer Server 已有的权限协议执行管理操作，因此 Launcher 和网页内“联机 / Users”面板使用的是同一套 Server 逻辑。

Launcher 可以：

- 查看正式 Player Users；
- 查看在线 / 离线状态；
- 查看待批准 Player；
- 批准首次加入的 Player；
- 预创建 User；
- 分配默认 Actor；
- 设置 `NONE / OBSERVER / OWNER`；
- 重发 Player Key；
- 删除 User；
- 查看 Actor 列表。

Server 负责最终写入：

```text
world/users.json
```

避免 Launcher 与运行中的 Server 出现两套不同的权限状态。

## 7. Player User 创建

### 玩家先申请

1. Player 打开地址。
2. 选择 Player，输入 Join Code。
3. 首次进入后成为 pending。
4. GM 在 Launcher 的“待批准玩家”中看到该 Player。
5. GM 选择默认 Actor 并批准。
6. Server 创建 Persistent User。
7. Player 获得对应角色权限。

GM 也可以继续在游戏内“联机 / Users”面板完成相同操作。

### GM 预创建

Launcher 的“预创建 User”可以在开团前创建 Player 身份。

创建后 Launcher 显示 Player Key。该 Key 应只私下发送给对应玩家。

## 8. Player Key

Quick Tunnel 重启后公网域名通常会变化，因此 RPGmap 同时使用：

- Browser Auth Token：同一网址自动重连；
- Player Key：新 Quick Tunnel URL 恢复同一个 Persistent User。

Launcher 可点击：

```text
重发 Player Key
```

新 Key 会使旧 Player Key 和旧浏览器身份失效。

Server 只保存凭证哈希，不保存明文 Key / Token。

## 9. Actor Ownership

权限：

- `NONE`：无控制权；
- `OBSERVER`：观察 / 查看；
- `OWNER`：可操控 Actor。

每个 Player 可以有一个默认 Actor，以及多个 OWNER / OBSERVER Actor。默认 Actor 必须是 OWNER。

GM 对全部 Actor 隐式拥有完整权限。

## 10. Combat Turn Lock

Combat active 后，Player 即使拥有多个 OWNER Actor，也只能操控当前 Turn 对应的那个 Actor。

GM 负责：

- Combatant 加入 / 移出；
- Initiative；
- 先攻排序；
- 开始 / 结束 Combat；
- Round / Turn 推进。

Player 可以查看 Combat Tracker，但管理控件为只读。

## 11. World / Maps

三条长期原则：

- `app/` = 程序是什么；
- `maps/` = Map / Scene 本身是什么；
- `world/` = 这一场游戏里发生了什么。

### world/

保存：User / Ownership、Actor / Token、Combat、Chat、地图实例状态、上传和备份。

### maps/

预留给真正地图系统：背景层、建筑、墙体、可破坏对象、碰撞 / Navigation、环境特效、损坏 / 摧毁变体等。

## 12. 备份与升级

最重要的备份对象：

```text
world/
```

如果有自定义地图，再同时备份：

```text
maps/
```

升级程序时不要覆盖自己的 `world/` 与 `maps/`。

RPGmap 默认不会把 World / User 数据写入 AppData 或其他隐藏用户目录。

## 13. 旧版本迁移

新 `world/` 文件不存在时继续兼容：

```text
V1.4.1 Candidate
map/world.json  -> world/state.json
map/users.json  -> world/users.json

更旧版本
data/worlds/default/world.json  -> world/state.json
data/worlds/default/access.json -> world/users.json
```

旧文件不会自动删除。

## 14. 关闭

在 Launcher 点击“停止服务器”只停止当前 RPGmap Server / Tunnel，Launcher 本身仍保持打开。

点击页面底部“关闭 Launcher”会同时停止：

- RPGmap Server；
- Cloudflare Tunnel；
- Launcher 后台进程。

## 15. 常用游戏操作

- Token 单选：左键
- 框选：空白地图左拖
- Shift：追加选择
- Alt：移除选择
- Token 移动：直接拖动
- Waypoint：Ctrl/Cmd + 点击或 `F`
- Enter：确认移动
- Esc：取消
- Ruler：`R`
- 从角色测距：`Shift + R`
- 切换 Form：`V`
