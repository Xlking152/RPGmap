## 原始目标验收

- [x] Actor 使用稳定通用外壳，规则专用数据由 Ruleset 管理并存放在 `actor.system`。
- [x] Ruleset Contract 覆盖默认数据、导入、旧存档迁移、规范化、验证、派生、展示/Sheet、属性路径和通用运行时操作。
- [x] Infinite Horror 兼容旧 health、B/L/A、形态、自定义资源、伤势、状态、自定义状态定义与 Synthetic Actor Delta。
- [x] Token、角色卡、聊天、导入器、Effect、Combat、Runtime 与多人服务器只依赖通用 Actor/Ruleset/World 接口。
- [x] 最小假 Ruleset 与源码边界测试证明 Core 不会补入 Infinite Horror 的 Health、B/L/A、状态 ID、默认伤害类型或阈值语义。
- [x] World-first 启动、显式 Ruleset 上下文、World 权威投影和通用多人 operation protocol 已作为独立检查点完成。
- [x] 普通多人写入使用原子 operation patch；完整 World 仅用于初始化、认证快照、显式导入、恢复与 revision gap 恢复。
- [x] 旧 `characters` / `characterId` 只存在于 SaveV1/V2 迁移或敌对兼容输入校验边界。
- [x] 没有遗留的已确认 P2/P3 架构阻塞项。
