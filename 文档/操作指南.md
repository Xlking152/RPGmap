# RPGmap v3.0.0 使用说明

RPGmap 的 GM 使用 Windows x64 桌面启动器；玩家使用 Microsoft Edge 或 Google Chrome 浏览器。安装器包含运行环境，不要求系统安装 Node.js。主机和玩家使用同一版本。

## 1. 安装与导入地图

正式交付文件为 RPGmap-Setup-3.0.0.exe、北宋兰州城-1.1.0.rpgmap、SHA256SUMS.txt 和本说明。可以放在同一普通文件夹中。

1. 运行安装器并打开桌面 RPGmap 图标，进入“管理首页”。
2. 首次启动地图列表为空。点击“导入地图 / 随附兰州地图”，选择 .rpgmap，查看名称、版本和兼容信息后确认。
3. 创建 World：填写游戏名称，选择规则和起始地图，再点击“创建 World”。
4. 点击对应 World 的“启动”或“进入游戏”。

导入会将地图复制到用户数据目录；成功后可移动原导入文件，已安装地图仍可运行。地图、规则和 World JSON 是不同内容，分别使用对应入口。

同版本同内容会复用；同版本不同内容拒绝覆盖。多个地图版本可以并存，新版不会自动替换已有场景引用。地图被 World、Scene 或恢复点引用时禁止卸载，管理页会显示引用位置。无引用地图可以卸载，升级程序不会复装兰州。

无限规则 infinite-horror@1.1.0 随应用提供。额外规则使用 .rpgrules，只导入信任作者提供的 RPGmap 契约包；规则包含可执行代码，不提供任意第三方脚本沙箱或 FVTT 插件兼容。

## 2. 玩家加入与权限

在管理首页“运行与数据”查看玩家加入地址及加入码。玩家打开 GM 的局域网地址，输入名称和加入码申请身份；GM 在游戏顶部“联机”面板批准，并分配角色权限。GM 密钥不能发给玩家。

| 权限 | 能力 |
| --- | --- |
| GM | 管理 World、场景、角色、权限与备份 |
| OWNER | 查看完整角色卡；Play 操作运行状态，Edit 修改获准的结构字段 |
| OBSERVER | 查看完整只读角色卡 |
| LIMITED | 仅看 GM 明确公开的简介、外观、情报与状态 |
| NONE | 不显示角色目录和角色卡 |

Actor 权限与 Token 控制权分开。怪物、NPC、召唤物需要实例上的显式控制者；拥有模板不等于可以移动全部实例。战斗中普通玩家只操作当前回合 Token。

跨地图重载在同一来源下自动恢复当前身份。换设备、换浏览器或修改服务端口后，可用 GM 分配的 Player Key 重新加入原身份。保管好 Player Key，不应公开分享。

局域网访问失败时检查主机实际地址、端口及专用网络防火墙规则。可使用 Radmin VPN 的同一虚拟网络与 GM 的 26.x.x.x 地址，先检查连接是否可达；真实 VPN 多机尚未完成本轮验收。只放行实际程序与端口，不关闭整个防火墙。

## 3. World 与多张地图

一场游戏对应一个 World，固定一个规则版本。每张游玩地图对应一个 Scene，并固定地图 ID、版本和内容。

GM 在游戏顶部选择“新场景的地图”，点击“＋ 场景”并输入名称，再从“当前场景”列表切换。同一地图可创建多个独立场景；也可在一个 World 中使用不同地图。GM 切换后所有玩家进入共同活动场景。

World 共享角色模板、资料和聊天；各 Scene 的 Token、实例状态、门、破坏、探索和设置独立。切图不会自动搬运 Token。跨地图或同地图不同版本可能重新加载页面，资源就绪前等待完成；缺少目标地图时补装相同版本，不以无碰撞底图继续。

## 4. 角色、实例与移动

GM 在“角色库”创建或导入 Actor，从 Token 页进入放置模式，再点击地图。按 Esc 可取消。PC 可使用共享角色 Token；怪物、NPC、召唤物各自保存生命、伤势、状态、资源和形态，修改一个实例不会修改模板或其他实例。

从地图打开 Token 实例卡处理当前生命与状态，从模板卡 Edit 模式修改属性和新实例默认值。角色卡可多开、拖动和缩放；LIMITED 玩家只能看到服务器授权的公共资料。

- 直接拖动 Token 并松开提交直线路线；路线不会自动绕开墙体。
- 拖动期间按住 Ctrl 并松开鼠标进入分段规划；Ctrl+点击或 F 添加拐点，右键或 Alt+F 撤销，Enter 确认，Esc 取消。
- WASD 连续移动会合并为有界路径；输入框和角色卡中的输入不会触发移动。
- 多选后拖动已选 Token，可保持相对队形群移。每个成员独立检查路径，一个受阻则整组不提交。
- 选择步行、游泳、水上行走或飞行需要规则能力或 GM 授权。高度统一为米；Shift+右键可打开高度操作，等于障碍顶部仍受阻。
- 移动、生命和状态需等待服务器确认。断线、权限变化或冲突时取消预览，不把本地显示当作已经保存。

战斗当前行动者离开回合起点后保留半透明起点幻影，仅用于观察，不是另一个 Token。GM 推进回合或结束战斗时更新或清除。

## 5. 地图交互、视野与破坏

“选择”同时用于 Token 与可检查地物。点击建筑、墙、门等查看详情；门有地图快捷控件，实际操作受权限、距离、锁和可见性约束。

“范围”提供圆形、扇形、矩形，可自由放置或绑定 Token/Marker。预览后应用地图破坏；支持局部或完整破坏、废墟、恢复与撤销。地物外观、移动阻挡和视线轮廓分别由地图声明，游玩改动只保存于当前 Scene。

GM 可在地物面板编辑遮挡 Tag、高度与轮廓。草稿先本地预览，再提交同步；门洞必须贯穿宿主墙体。导出的遮挡配置用于制图，不包含角色或游玩进度。

玩家点击自己控制的 Token，选为本会话实时视野来源。同队共享历史探索，不共享其他玩家的实时亮区。精确范围清晰，模糊范围有薄雾，历史区域变暗，未探索区域近黑。隐身和隐藏实体由服务端权限裁剪；地图底图资源本身仍会下载，迷雾不是底图保密机制。

“指示物”可管理怪物、NPC 和其他模板，放置陷阱、目标点、区域与注释。聊天、战斗、资料库、Journal 及状态都以服务器 World 为准。独立怪物/NPC 状态修改应针对实例，不能从模板向所有同源实例扣血。

## 6. 两种重置与恢复点

两个操作均仅 GM 可执行，先显示影响范围并成功建立恢复点，再提交。备份失败则不重置。

| 内容 | 恢复地图环境 | 清空当前场景 |
| --- | --- | --- |
| 门、破坏、地物与遮挡覆盖 | 回到固定地图版本默认状态 | 同左 |
| 历史探索 | 清除，按保留 Token 重算当前视野 | 清除 |
| Token、实例状态、标记、范围模板 | 保留 | 清除 |
| 当前场景战斗记录 | 保留并更新空间结果 | 清除 |
| Scene 设置 | 保留 | 恢复默认 |

两者保留 Scene 身份、名称和地图版本，以及 World 角色、模板、资料、聊天和其他场景。恢复环境后若 Token 与恢复的墙体冲突，会提示 GM 调整，不自动移位。

管理首页可“建立恢复点”，再选择恢复点点击“恢复”。恢复会替换对应 World 及权限等关联数据，操作前也会保存当前状态；读取确认内容后再执行。

## 7. 存档、旧数据与升级

默认用户数据目录：

~~~text
%LOCALAPPDATA%\RPGmap\UserData
~~~

这里保存 World、权限、WAL、地图和规则版本、上传、备份、配置及日志。管理首页可“打开用户数据目录”。备份前正常“保存并退出”，复制完整 UserData，避免只拿 World JSON 而漏掉权限、内容包或上传。

从 v2.5.5 迁移时先导入兰州地图，再使用“导入旧版数据目录”选择旧 map/。程序复制 World、WAL、权限、上传及备份，校验迁移副本，成功前保留原目录。仅有导出的 JSON 则使用“导入旧版存档”；旧浏览器离线数据需要先显式导出，再导入新 World。

升级时下载新版安装器及对应 SHA256SUMS.txt。在首页“运行新版安装器”选择安装器，校验后正常停服安装；也可保存退出后直接运行安装器覆盖。升级不要求重新导入地图，卸载程序也保留 UserData。重装会读取保留的数据。首次使用未知新旧数据格式时先保留完整备份，不直接用旧程序强读。

程序文件损坏时停止启动，重新运行正确安装器修复。安装器会保留旧程序恢复副本；首版没有自动回滚功能。存档损坏或版本缺失时保留文件并从完整恢复点处理，不创建空 World 覆盖原数据。

## 8. 已知限制与排查

- 浏览器七会话性能验证出现超过 100 ms 的长任务，两次正式运行未通过该门槛；按用户决定暂缓排查，不能确认是其他游戏造成。
- 干净 Windows（无 Node/仓库/缓存）、真实 VPN 多机、真实安装中断及自动回滚未完成验证；现有本机安装和联机结果不替代这些环境。
- 当前每个 World 只有一个全体共享的活动场景，不支持每个玩家单独切图、自动跨图传送、完整制图编辑器、完整 DND/COC 或在线自动更新。
- 玩家不能移动时依次检查实例控制者、战斗回合、状态能力、路径和高度；生命和状态也应从正确实例操作。
- 刷新不清空历史探索。看不到目标时检查服务器可见性授权、当前 Token 视野和隐身，而非只看地图画面。
- 端口改变后使用新地址重新加入；服务停用时浏览器不切换到离线权威模式。等待重连后继续编辑。
