# RPGmap 工作日志

当前开发版本：**1.4.3 Candidate**  
当前稳定 `main`：**1.4.0**

## 1.4.3 Candidate — 2026-08-22

V1.4.3 的目标是把 V1.4.2 的 `app / world / maps` 便携结构继续整理成一个真正易用的 GM 启动与管理中心。

### 最终启动方案

最终 Windows 发布包根目录只保留：

```text
RPGmap.bat
```

BAT 直接执行：

```text
node launcher\launcher.mjs
```

不再使用 PowerShell Start-Process、不再套隐藏 CMD，也不再提供 Native EXE。

Node 查找顺序：

```text
tools/node/node.exe
→ 根目录 node.exe
→ 系统 PATH node.exe
```

BAT 窗口作为 Launcher Runtime 保持运行，可最小化；所有 GM 操作、联机信息、Users 和日志都集中在浏览器 Launcher 中。

### Native EXE 尝试与撤回

开发过程中曾实现轻量 Windows C Launcher，并由 MinGW 编译为 `RPGmap Launcher.exe`。自动化 Windows 环境可以运行，但真实 Windows 实机测试出现：

- EXE 双击后无界面；
- 后台 Node 退出时反馈不直观；
- 端口冲突出现 `exit code 0`；
- 启动壳本身增加了额外诊断层。

因此最终撤回：

- 删除 `windows-launcher.c`；
- 删除 MinGW EXE 构建；
- 发布包根目录 EXE 数量固定为 0；
- 回到最透明的 BAT + Web Launcher。

### ASCII BAT 文件名

早期准备使用中文 `启动 RPGmap.bat`。Windows 英文 Runner 暴露出 cmd 代码页/区域设置对中文 BAT 文件名调用不稳定的问题。

因此最终使用：

```text
RPGmap.bat
```

保证中文 / 英文 Windows 都能稳定调用。

### 动态 Launcher 端口

Launcher 只绑定 `127.0.0.1`。

```text
29999
→ 29998
→ 29997
→ 29996
→ 29995
→ Windows 自动分配空闲端口
```

不按端口强杀未知进程。浏览器自动打开最终地址。

Game Server 仍默认使用 `30000`。

### Unified Web Launcher

Launcher 页面统一显示和管理：

- Local / LAN / Internet；
- Server / Tunnel lifecycle；
- Local / LAN / Public URL；
- Join Code；
- GM Secret；
- Player Invite；
- World / Maps 路径；
- Server / Tunnel logs。

Internet 模式使用 Cloudflare Quick Tunnel + HTTP/2 over TCP，缺少 cloudflared 时下载到：

```text
tools/cloudflared.exe
```

### Launcher Admin Console

Launcher 通过隐藏 GM WebSocket Session 复用 Server `access.*` 协议：

- pending approve；
- User create/update/delete；
- Default Actor；
- NONE / OBSERVER / OWNER；
- Player Key rotation；
- online / Actor catalog。

Launcher 不直接写 `world/users.json`。

### Future Manager Slots

Launcher 已预留：

- World Manager；
- Scene Manager；
- Backup Center。

按钮当前保持禁用，未来直接在现有 Launcher 布局中扩展。
