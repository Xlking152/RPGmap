# RPGmap 工作日志

当前开发版本：**1.4.3 Candidate**  
当前稳定 `main`：**1.4.0**

## 1.4.3 Candidate — 2026-08-22

### 最终启动架构

经过 Native EXE 和多层隐藏进程方案实机测试后，V1.4.3 最终收口为：

```text
RPGmap.bat
    ↓
PowerShell Runtime
    ↓
Node.js launcher/launcher.mjs
    ↓
Web Launcher / GM Control Center
```

根目录唯一入口为 `RPGmap.bat`，EXE 数量固定为 0。

### PowerShell Runtime

新增：

```text
deployment/launcher/rpgmap-runtime.ps1
```

职责只包括：

- 查找 Node.js；
- 作为 Launcher Node 进程宿主；
- 保持一个稳定、可最小化的信息窗口；
- 显示 Launcher / Server / Tunnel stdout；
- Server READY 后显示 Local / LAN / Public URL、Join Code、GM Secret、World / Maps、Build；
- 显示后续 Server / Tunnel 日志。

PowerShell 不承担 User / Ownership 等业务逻辑，真正的 GM 操作仍全部位于 Web Launcher。

Node 查找顺序：

```text
tools/node/node.exe
→ 根目录 node.exe
→ 系统 PATH node.exe
```

### 为什么撤回 EXE

曾实现 `RPGmap Launcher.exe` 和 `windows-launcher.c`，并通过自动化 Windows Smoke Test。但真实设备出现双击无界面、后台错误反馈不直观、端口冲突诊断复杂等问题。

因此：

- Native EXE 方案撤回；
- `windows-launcher.c` 删除；
- MinGW 构建删除；
- 当前优先 BAT + PowerShell + Web Launcher。

### 动态 Launcher 端口

Launcher 只绑定 loopback：

```text
29999 → 29998 → 29997 → 29996 → 29995 → Windows 自动空闲端口
```

不根据端口强杀未知进程。浏览器自动打开最终地址。
