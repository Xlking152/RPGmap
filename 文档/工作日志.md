# RPGmap 工作日志

本文件只记录**应用版本级别的重要更新**，不记录每次提交、CI 构建编号或临时测试 Tag。

当前版本：**1.2.0**

## 版本规则

RPGmap 使用 `MAJOR.MINOR.PATCH`：

- `PATCH`：Bug 修复、小型 UI / 交互调整、兼容性修正，例如 `1.2.1`。
- `MINOR`：新增较完整功能、子系统或明显能力扩展，例如 `1.3.0`。
- `MAJOR`：存在明显不兼容的存档、服务器协议、World 数据或核心架构变化，例如 `2.0.0`。

普通提交和测试包不会自动提升应用版本。后续当开发内容达到新的版本节点时，先提出建议版本和理由，经确认后再修改版本号并在这里记录。

## 当前开发批次 — 2026-08-21（未发布，版本号仍为 1.2.0）

本批次继续将 RPGmap 从基础地图工具完善为可实际跑团使用的通用 VTT。当前改动集中在 Draft PR #3，完成实际测试并确认版本后再归入正式版本节点。

### Actor Sheet / XLSX

- “鉴定”页重新归类为技能鉴定与真正的意志、反射、强韧豁免，读取 `具体数值表 → 检定速查` 的最终缓存值，不执行 Excel 公式。
- 新增“不良状态”页，支持 21 种不良状态的当前值、轻度、重度、毁灭标准。
- 不良状态当前值属于 Actor Runtime；阈值属于当前 Form，因此切换形态时阈值变化、当前点数保留。
- 兼容迁移旧 1.2.0 中误存入 `checks.saves` 的不良状态阈值数据。

### MeasurementSystem / Ruler

- 删除活动 UI 中旧“两点测距 / 路线测距”分裂入口，统一为 FVTT 风格 Ruler。
- 支持普通两点测距与 Waypoint 折线测距；`R` 开关，`Ctrl/Cmd + 左键` 或 `F` 添加拐点，右键或 `Alt+F` 撤销，`Esc` 清除。
- 新增“角色测距”，可从当前主选择 Token 的位置直接作为 Ruler 起点，支持 `Shift + R`。
- Movement 和 Ruler 的距离标签统一使用高层 `pathLabelPane`，移动路线和测量线不能遮挡距离数字。

### SelectionSystem

- 新增 Token 多选与矩形框选：空白地图左拖框选，`Shift` 追加，`Alt` 移除，点击空白清空。
- Token 本身左拖仍由 MovementSystem 接管；`Space + 左拖` 保留地图平移。
- Selection 作为 Combat、角色测距和伤害应用的统一目标来源。

### CombatSystem

- 新增左侧先攻表与顶部战斗控制。
- 只有当前明确选中的 Token 会进入战斗；战斗建立后新 Token 不会自动加入，需要再次选择并点击“加入所选”。
- 先攻由操作者手动输入，默认按高到低排序，并支持拖动手动调整最终顺序。
- 支持开始战斗、轮次 / 当前回合、下一回合与结束战斗；当前回合同时高亮先攻表与地图 Token。
- Combatant 只引用 Actor / Token，不复制角色资源。
- 战斗建立、加入参战者、回合推进、退出和结束等事件开始写入 Game Log。

### HealthSystem / DamageSystem

- 保留原有 `SimpleHP` 普通 HP 模式，以支持后续其他规则游戏。
- 新增可切换的 `WoundTrack` 伤势生命槽模式；当前 XLSX 角色默认采用该模式。
- WoundTrack 按当前规则使用“完好 / B 冲击 / L 严重 / A 恶性”生命槽，伤害溢出按 B → L → A 的升级逻辑处理。
- 无完好生命槽时标记昏迷；生命槽全部为 A 时标记死亡；无完好且存在 A 时提示伤势恶化。
- 伤势恶化暂不自动每轮扣除，只显示状态与提示，避免绕过急救、治疗和特殊能力。
- DamageSystem 提供通用“向所选 Token 应用最终伤害”的接口；防具、硬度、DR、免疫、临时生命等伤害前置步骤暂由操作者结算。

### ChatSystem / Game Log

- 右侧栏扩展为“聊天 / 角色库 / 当前”。
- ChatSystem 持久化普通消息、系统消息、战斗事件、伤害事件，并预留 `roll` 类型作为后续骰子接口。
- 聊天区提供“消息 / 伤害”输入模式；输入最终伤害值和 B/L/A 级别后，可直接应用到当前所选角色。
- 伤害日志记录目标、伤害前后生命状态、昏迷 / 死亡 / 伤势恶化提示。
- 后续 DiceSystem、技能检定和战斗计算均可复用同一 Game Log，不再各自维护历史窗口。

### MapPackage 展示清理

- 地图展示层移除“推定 / 推测 / 位置推测 / 线位推测”等不必要的推测性后缀。
- 保留日期、单位等具有实际信息的括号内容；只清理展示名称，不破坏 MapPackage 原始资料。

## 1.2.0 — 2026-08-21

本版本将 RPGmap 从“单张地图工具”进一步重构为可扩展的 VTT 基础框架。

### MovementSystem

- 将角色移动整理为独立 MovementSystem。
- Token 支持直接拖动规划路线、A* 寻路、Ghost Token 和分段距离显示。
- 支持 Waypoint 路径：`Ctrl/Cmd + 左键` 或 `F` 添加，右键或 `Alt+F` 撤销，`Enter` 确认，`Esc` 取消。
- `Ctrl/Cmd` 拖动松开只进入 Waypoint 规划，不再把松开位置错误记录为 waypoint 1。
- 支持 5 / 10 / 20 / 50 / 100 m 吸附档位，规划中滚轮切换，已固定 waypoint 保持不变。
- 距离标签改为悬浮在线路上方，避免被移动线遮挡。

### EntitySystem

- 建立 Actor / Token 两层模型。
- Actor 负责身份、头像、属性、资源、技能 / 豁免、Forms、Runtime 和 Effects。
- Token 负责地图位置和场景状态，并与 MovementSystem 衔接。
- 支持多 Form，例如“变身前 / 变身后”；选中 Token 后按 `V` 可快速切换形态。
- HP、精力、意志和自定义资源槽可实时修改。
- 数据区分 Base / Runtime / Effects，为伤害、治疗、Buff、Debuff 和特殊能力保留统一修改路径。
- Effects 预留 `add / multiply / set / min / max` 修改模式。

### XLSX 角色导入

- 支持从现有角色卡 XLSX 导入 Actor。
- 当前模板只读取 `角色概览` 和 `具体数值表`。
- 只读取 Excel 已保存的最终缓存值，不执行或保存公式。
- 支持身份信息、头像、生命、精力、意志、基础属性、技能和豁免 / 抵抗数据。
- 攻击 / 防御和复杂速度规则暂时保留扩展接口。

### AppShell UI

- 顶层 UI 收口为：选择、测量、范围、场景、导入角色、存档。
- 右侧面板整合为角色库与当前对象 Inspector。
- 移除新 UI 中旧 Marker 和“移动角色”独立入口，Token Drag 成为标准移动方式。
- 增加 Token 右键菜单、Movement HUD 和底部状态栏。

### Server / Deployment

- 建立本地 HTTP Server 测试包，默认端口 `30000`，可供局域网浏览器访问。
- 提供 Windows / Linux / macOS 启动入口。
- 发布包不包含 `.git`、`node_modules`、测试缓存和历史参考文件。
- Windows 发布路径统一使用 ASCII 文件名，避免 ZIP / CMD 代码页乱码。
- 后续 GitHub Release 改为按应用版本发布，例如 `v1.2.0`，不再使用连续 Server 构建编号作为产品版本。

### 项目整理

- 项目正式统一命名为 **RPGmap**，不再以“北宋兰州地图”作为项目身份。
- 北宋兰州保留为第一张 MapPackage / 验证地图，后续计划整合更多地图。
- README 重写为产品说明、功能介绍、快捷键和运行方式。
- 工作记录统一为本文件；旧的 CHANGELOG、工作留痕、历史参考和单地图成品校验资料退出当前开发文档体系。
