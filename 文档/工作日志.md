# RPGmap 工作日志

本文件记录应用版本级别的重要更新。更精炼的正式版本摘要见根目录 `CHANGELOG.md`；更细的提交历史可通过 Git 查看。

当前版本：**1.4.0**

## 版本规则

RPGmap 使用 `MAJOR.MINOR.PATCH`：

- `PATCH`：Bug 修复、小型 UI / 交互调整、兼容性修正，例如 `1.4.1`。
- `MINOR`：新增较完整功能、子系统或明显能力扩展，例如 `1.5.0`。
- `MAJOR`：存在明显不兼容的存档、服务器协议、World 数据或核心架构变化，例如 `2.0.0`。

## 1.4.0 — 2026-08-21

本版本完成 Multiplayer V1，将 RPGmap 从本机 / 局域网 VTT 扩展为可通过 WebSocket 共享 World 的自托管多人跑团工具，并加入 Windows 一键远程联机。

### Multiplayer Server / World Store

- `deployment/local-server/server.mjs` 新增原生 WebSocket `/ws`。
- 新增 `data/worlds/<world-id>/world.json` World Store。
- World 保存 revision、更新时间与共享 Snapshot，并使用临时文件 + rename 原子写入。
- 新增 `hello / welcome / presence / world.push / world.snapshot / world.conflict / world.request` 协议。
- 客户端提交使用 `baseRevision`；落后时 Server 返回最新 Snapshot。
- Server 重启后恢复持久化 World。
- `/api/health` 和 `/api/multiplayer` 提供当前多人状态；公网模式附带 `publicUrl`。

### GM / Player

- 当前身份模型为 `GM` / `Player`。
- Player 使用 Join Code；GM 使用 GM Secret。
- 公网模式下正确 GM Secret 可以直接授权 GM，不再被 Player Join Code 阻挡。
- 修复 GM / Player 已收到 welcome、顶栏显示在线但联机遮罩仍未关闭的问题。
- 当前默认允许 Player 写共享 World；Actor Ownership 和细粒度权限后续继续开发。

### Client 同步

- 新增 `src/multiplayer/`。
- `http://` 自动连接 `ws://`，`https://` 自动连接 `wss://`。
- 第一阶段同步 Actor、Token、Health、Damage、Healing、Combat、Chat / Game Log、Scene 等 World 状态。
- Selection、Ruler、地图视角和其他临时 UI 不进入共享 World。
- 新玩家加入或断线重连后取得 Server 最新 Snapshot。

### Internet Multiplayer

- 新增 `start-rpgmap-internet.bat`。
- 新增 `setup-cloudflared.bat`，自动检测本地 / PATH 中 cloudflared，并尝试官方下载或 winget 安装。
- 新增 `internet-launcher.mjs`，统一管理 Tunnel、Server、健康检查、浏览器启动与退出。
- Cloudflare Quick Tunnel 默认强制 HTTP/2 over TCP，提高 VPN / TUN、校园网和限制 UDP 环境下的兼容性。
- Launcher 自动解析 `https://*.trycloudflare.com`，并通过 `RPGMAP_PUBLIC_URL` 注入 Server。
- 自动生成 6 位 Player Join Code 和随机 GM Secret。
- Server READY 信息块直接显示 Public URL。
- Windows 额外打开独立 `RPGmap Multiplayer Info` 信息窗口，集中显示 Public URL、Join Code、GM Secret 和 Local URL，方便复制与观察。
- 玩家只需要 Public URL + Join Code；GM Secret 只供 GM 使用。

### WebSocket 稳定性

- 增加 RSV / unsupported extension 校验。
- 增加控制帧长度校验。
- 增加分片消息总长度限制。
- 拒绝 nested fragments、unexpected continuation 和不完整 fragment sequence。
- 保留最大 payload 限制，降低异常消息风险。

### 测试 / CI

- 保留 Multiplayer Client protocol helper 测试。
- 保留真实 Node Server + 多 WebSocket Client World 同步测试。
- 增加公网 GM Secret / Player Join Code 身份验证测试。
- 增加 Quick Tunnel URL 日志解析测试。
- 增加 Join Code / GM Secret 格式测试。
- 增加 Multiplayer Connection Info 内容测试。
- GitHub Actions 统一执行 `npm test`、JS syntax check、production build 和 ZIP 组装。

### 文档 / Release

- 根 README 更新 Multiplayer、World Store 和远程联机说明。
- 新增根 `CHANGELOG.md`。

## 1.3.0 — 2026-08-21

1.3.0 将 RPGmap 完善为能够完成角色导入、地图选择与移动、测距、先攻战斗、伤害 / 恢复结算以及 Game Log 的一体化单机 / 局域网跑团工作流。

### 主要内容

- Actor Sheet：技能 / 豁免、不良状态、多 Form 与 XLSX 最终缓存值导入。
- SelectionSystem：Token 单选、多选、矩形框选，支持 Shift 追加、Alt 移除。
- MeasurementSystem：FVTT 风格 Ruler、Waypoint 与角色测距。
- CombatSystem：手填先攻、拖动排序、轮次 / 当前回合与显式加入参战者。
- HealthSystem：SimpleHP 与完好 / B / L / A WoundTrack。
- DamageSystem / HealingSystem：对所选 Token 应用最终伤害或实际恢复量。
- Token 生命条：SimpleHP 比例条与 WoundTrack 分段生命槽。
- Chat / Game Log：普通聊天、战斗、伤害、恢复记录。
- HTTP Server：发布包不依赖 Vite dev/preview 即可运行。
