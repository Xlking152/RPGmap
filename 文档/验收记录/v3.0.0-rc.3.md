## 失败与按用户要求暂缓

首次完整七浏览器测量 normal 阶段 GM/Player 5 的长任务为 136/145 ms；固定静默复核 normal 阶段 Player 1/Player 5 为 370/107 ms，均超过原 100 ms 上限。两个 dark 阶段无原生长任务，其他已记录指标不能抵消该失败。

两次诊断未复现以上停顿，现有 trace 不支持认定 GC、JIT、布局或操作系统调度为根因。用户随后说明可能同时运行其他游戏，并明确要求暂时不管延迟。本轮据此停止进一步诊断与性能重测，未修改门槛、未把失败改判通过；“其他游戏影响”只是可能条件。未提交的后续诊断实验已撤回，保留通过全量测试的 `8051bd27c6ac224935434e79c031dcc3f4ecc8f2` 驱动。

现有失败、有效 gzip trace、无效补充采集的失败记录、原始阶段与准备等待计时均保留。准备等待与结构提交/画面反馈分别计量，不把等待藏入或移出原普通移动门槛来取得通过。
