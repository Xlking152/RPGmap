# RPGmap Multiplayer V1 联机测试指南

当前正式版本仍为 **1.3.0**。本指南对应 `feat/multiplayer-v1` 开发分支，用于验证下一阶段 Multiplayer V1 的核心联机能力；通过测试并确认版本后，再决定是否正式发布为 1.4.0。

## 一、这一轮重点测试什么

本轮优先验证“多台设备能否稳定共享同一个 RPGmap World”，而不是一次完成全部权限系统。

重点同步：

- Token / 角色位置与创建、删除；
- Actor / Form / 资源 / 不良状态；
- Health / Damage / Healing；
- Combat；
- Chat / Game Log；
- 场景破坏与恢复；
- 服务器 World 持久化与重新加入。

Selection、Ruler、地图视角、Hover、打开的窗口等个人 UI Runtime 状态不作为共享 World 数据。

## 二、当前同步模型

Multiplayer V1 测试阶段先采用 **Server-authoritative World Snapshot**：

```text
Client 本地操作
      ↓
导出当前 World Snapshot
      ↓
WebSocket /ws
      ↓
RPGmap Server
      ↓
revision 校验
      ↓
写入 data/worlds/default/world.json
      ↓
广播最新 Snapshot
      ↓
其他 Client 导入并刷新
```

服务器保存 `revision`。客户端提交时携带 `baseRevision`；如果已经落后，服务器拒绝旧写入并返回最新 Snapshot，避免直接覆盖更新后的 World。

当前测试模式默认允许 GM 和 Player 都提交 World 改动，目的是优先验证 Token、Health、Combat、Chat 等双向联机是否稳定。后续再在这个稳定链路上增加 Actor Ownership 和更细粒度 Action / Event 权限。

## 三、局域网测试

### 1. GM / 主机

在主机电脑解压测试包并启动：

```text
Windows: start-rpgmap.bat
Linux/macOS: ./start-rpgmap.sh
```

Server 会显示类似：

```text
Local   : http://127.0.0.1:30000
Network : http://192.168.1.105:30000
World   : default · revision 0
GMSecret: XXXXXXXX
```

主机浏览器打开 Local 地址，在“RPGmap 多人联机”窗口中：

```text
显示名称：任意
身份：GM
房间码：留空（默认未启用）
GM Secret：主机本机、非公网模式可留空
```

第一次 World 为空时，GM 客户端会把当前本地状态初始化到服务器。

### 2. Player

同一局域网的另一台电脑 / 手机 / 平板直接打开主机显示的 Network 地址，例如：

```text
http://192.168.1.105:30000
```

加入窗口选择：

```text
显示名称：玩家名字
身份：Player
```

连接成功后顶部“联机”按钮会显示 `GM · N人` 或 `Player · N人`。

## 四、建议逐项测试

1. GM 放置 / 移动 Token，Player 是否同步；
2. Player 移动 Token，GM 是否同步；
3. GM / Player 修改角色资源、不良状态或切换 Form；
4. 应用 B / L / A 伤害，另一端的角色卡、Token 血条和 Game Log 是否同时变化；
5. 执行恢复，另一端是否同步；
6. 加入 Combat、填写先攻、拖动顺序、下一回合，另一端是否同步；
7. 双方发送 Chat，Game Log 是否同步；
8. 场景破坏 / 恢复是否同步；
9. Player 刷新浏览器后，是否重新取得服务器当前 World；
10. 关闭并重新启动 Server 后，`data/worlds/default/world.json` 中的 World 是否恢复。

如果两人同时在极短时间内修改 World，测试版可能出现 `conflict-reload`，此时客户端会接受 Server 的最新 revision。请记录具体操作顺序，后续用于拆分高频 Action / Event。

## 五、跨互联网测试

### 推荐：Tailscale / ZeroTier

先让 GM 和 Player 的设备加入同一个虚拟局域网，然后 Player 使用 GM 电脑的虚拟网 IP 访问：

```text
http://<GM 的 Tailscale/ZeroTier IP>:30000
```

RPGmap 本身不需要切换协议；WebSocket 会继续连接同一 Host 的 `/ws`。

### HTTPS Tunnel

如果使用 Cloudflare Tunnel 等 HTTPS 入口，浏览器端会自动从：

```text
http  → ws
https → wss
```

公网模式建议启动 Server 时设置：

```text
RPGMAP_PUBLIC=1
RPGMAP_GM_SECRET=<自定义 GM Secret>
RPGMAP_JOIN_CODE=<可选 Player 房间码>
```

在 `RPGMAP_PUBLIC=1` 时，不依赖“本机连接自动获得 GM”的逻辑；远程 GM 应使用 GM Secret。

## 六、当前已知边界

- 当前是 Multiplayer V1 联机链路测试，不是最终权限系统；
- Player 默认可写，用于验证双向操作，后续再实现 Actor Ownership；
- 当前以完整 World Snapshot 同步，稳定后再拆分 `token.move`、`actor.damage`、`combat.nextTurn`、`chat.send` 等 Action / Event；
- 暂不做账号、密码、邮箱、OAuth、JWT；身份只保留 GM / Player；
- 暂不自动配置 Tailscale、ZeroTier 或 Cloudflare Tunnel，这些只提供网络通道，RPGmap 仍由自己的 Server / WebSocket 同步 World；
- 学校、酒店或公共 Wi-Fi 可能启用客户端隔离，导致同一 Wi-Fi 下设备之间不能直连。
