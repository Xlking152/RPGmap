# RPGmap 1.4.0 联机使用说明

本文说明 RPGmap V1.4 的 GM / Player、局域网联机和公网远程联机流程。

## 1. 需要准备什么

主机电脑需要：

- RPGmap 1.4.0 完整发布包
- Node.js `^20.19.0 || >=22.12.0`
- Windows 公网联机时需要 `cloudflared`；启动脚本会自动检测，并在缺失时尝试下载安装

玩家只需要现代浏览器，不需要安装 Node.js 或 cloudflared。

## 2. 最简单的远程联机方法（Windows）

主机双击：

```text
start-rpgmap-internet.bat
```

启动器会依次完成：

1. 检测 `cloudflared.exe`。
2. 创建 Cloudflare Quick Tunnel。
3. 从 Cloudflare 日志中自动读取 `https://*.trycloudflare.com` 公网地址。
4. 生成 6 位 `Join Code`。
5. 生成随机 `GM Secret`。
6. 启动 RPGmap Multiplayer Server。
7. 检查 `/api/health`，确认 Server 已 READY。
8. 自动打开公网 RPGmap 页面。
9. 打开一个独立的 `RPGmap Multiplayer Info` 信息窗口。

信息窗口会显示类似：

```text
============================================================
 RPGmap Multiplayer Connection Info  |  1.4.0
============================================================
 Public URL : https://example-room.trycloudflare.com
 Join Code  : 313303
 GM Secret  : 163E125385CAB02C
 Local URL  : http://127.0.0.1:30000
============================================================

 PLAYER SHARE ONLY:
   URL       : https://example-room.trycloudflare.com
   Join Code : 313303
```

## 3. 发给玩家什么

只发：

```text
Public URL + Join Code
```

例如：

```text
RPGmap 地址：https://example-room.trycloudflare.com
房间码：313303
```

不要发送：

- `GM Secret`
- `http://127.0.0.1:30000`
- 本机 `Network` 地址（异地玩家无法直接使用）
- Data 路径或 Build 信息

## 4. GM 怎么进入

GM 打开 RPGmap 后：

1. 选择身份 `GM`。
2. 填写显示名称。
3. `Join Code` 可以留空。
4. 填写信息窗口中的 `GM Secret`。
5. 点击加入。

登录成功后顶栏会显示 GM 身份和当前在线人数，登录遮罩层自动关闭。

## 5. Player 怎么进入

Player：

1. 在浏览器打开 GM 发来的公网 HTTPS 地址。
2. 选择身份 `Player`。
3. 填写显示名称。
4. 输入 GM 发来的 6 位 Join Code。
5. `GM Secret` 保持空白。
6. 点击加入。

登录成功后 Player 会取得 Server 当前 World Snapshot。

## 6. 局域网联机

如果 GM 和 Player 在同一个 Wi-Fi / 局域网：

1. 主机运行 `start-rpgmap.bat`。
2. 启动窗口会显示一个或多个 `Network` 地址，例如：

```text
http://192.168.1.4:30000
```

3. 同一局域网玩家直接打开该地址。

如果仅在局域网中使用，不需要 Cloudflare Quick Tunnel。

## 7. 同步哪些内容

当前 V1.4 World Snapshot 同步主要包含：

- Actor / Token
- Token 位置
- Health / Damage / Healing
- Combat / Initiative / Round / Turn
- Chat / Game Log
- Scene / World 持久状态

以下属于个人临时 UI，不同步：

- 当前 Selection
- Ruler
- 地图缩放 / 视角
- Hover
- 当前打开的窗口 / 面板

## 8. World 保存在哪里

默认：

```text
data/worlds/default/world.json
```

Server 重启后会尝试恢复该 World。

每次 World 更新都会增加 `revision`。如果两个客户端同时基于旧 revision 修改，Server 会返回最新 Snapshot，避免旧客户端直接覆盖新状态。

## 9. Cloudflare Quick Tunnel

V1.4 的 Windows 远程入口使用 Cloudflare Quick Tunnel：

- 不要求 Cloudflare 账号
- 不要求自有域名
- 自动提供 HTTPS
- RPGmap 自动使用对应的 WSS WebSocket
- 每次启动通常会得到新的随机 `trycloudflare.com` 地址
- 关闭 RPGmap Internet Launcher 后该地址失效

当前启动器强制使用 `HTTP/2 over TCP`，以提升在 VPN / TUN、校园网或限制 UDP 的网络环境中的兼容性。

Quick Tunnel 适合个人跑团和便捷测试，不是长期固定域名方案。长期公网服务器后续建议使用 Named Tunnel / 自有域名。

## 10. 常见问题

### 玩家打不开公网地址

先用 GM 自己的手机关闭 Wi-Fi，切换 4G / 5G 后访问 Public URL：

- 如果手机流量可以打开，主机和 Tunnel 基本正常，应检查玩家网络。
- 如果手机流量也打不开，检查主启动窗口的 Cloudflare 日志。

### Cloudflare 日志出现 `stream ... canceled by remote`

单次出现不一定意味着 Tunnel 整体失效，可能只是浏览器取消了某个请求。应以公网页面是否能打开、WebSocket 是否能正常登录为主要判断依据。

### 找不到 cloudflared

`start-rpgmap-internet.bat` 会依次尝试：

1. RPGmap 目录中的 `cloudflared.exe`
2. 系统 PATH 中的 `cloudflared.exe`
3. 官方 GitHub Release 下载
4. `winget install --id Cloudflare.cloudflared --exact`

如果自动方式失败，也可以手动下载 Windows 64-bit `cloudflared.exe` 放到 RPGmap 根目录。

### 已显示 GM / Player 在线但登录窗口没有关闭

V1.4 已修复该问题。联机遮罩现在同时使用 `hidden` 与显式 `display:none`，GM / Player 收到 `welcome` 后都会退出登录界面。

## 11. 当前权限边界

V1.4 目前采用轻量 GM / Player 模型：

- 无账号注册
- 无邮箱 / OAuth / JWT
- Player 使用 Join Code
- GM 使用 GM Secret
- 默认允许 Player 写共享 World

不要把 GM Secret 发到玩家群或公开论坛。每次公网启动都会重新生成随机 GM Secret 和 Join Code。

## 12. 建议的首次联机检查

第一次正式跑团前建议用两台设备测试：

1. GM 登录。
2. Player 登录。
3. GM 移动 Token，确认 Player 同步。
4. Player 移动 Token，确认 GM 同步。
5. 测试 Damage / Healing 与生命条。
6. 测试 Combat / 下一回合。
7. 测试 Chat / Game Log。
8. Player 刷新页面，确认能重新加载 Server World。
9. 重启 Server，确认 `world.json` 可以恢复。

如果以上均正常，即可按当前 V1.4 Multiplayer 流程使用。
