# RPGmap 1.5.3 联机使用说明

V1.5.3 将 Windows 启动入口统一为一个文件：

```text
start-rpgmap.bat
```

双击后选择：

```text
1. Local / LAN
2. Internet / Public
```

不再需要理解或手动运行其他 BAT。

---

## 1. 便携目录

```text
RPGmap-v1.5.3/
├─ app/                    构建后的前端程序
├─ map/                    当前 World / User 可写数据
│  ├─ world.json
│  ├─ users.json
│  ├─ uploads/
│  └─ backups/
├─ reference/              MapPackage / DIY 参考，Runtime 不依赖
├─ docs/
├─ server.mjs
├─ launcher.mjs            Local / LAN / Internet 统一启动逻辑
├─ access-control.mjs
├─ portable-storage.mjs
└─ start-rpgmap.bat        Windows 唯一启动入口
```

核心原则：**World / User / Ownership / 上传资源默认只写在当前包自己的 `map/`。** 升级程序时优先保留整个 `map/`。

---

## 2. Local / LAN

双击 `start-rpgmap.bat`，选择：

```text
1. Local / LAN
```

Launcher 会先检查端口，再启动 Server，等待 `/api/health` READY，最后才打开浏览器。

主机本机使用：

```text
http://127.0.0.1:30000
```

同一局域网的 Player 使用启动窗口显示的 `Network` 地址，例如：

```text
http://192.168.1.4:30000
```

Local 模式明确使用 `publicMode=false`，不会创建 Cloudflare Tunnel。

---

## 3. Internet / Public

双击同一个 `start-rpgmap.bat`，选择：

```text
2. Internet / Public
```

Launcher 会自动：

1. 检查 `30000` 是否已被占用；
2. 查找本地或系统 `cloudflared`；
3. Windows 缺少时尝试自动安装 portable `cloudflared.exe`，失败后尝试 Winget；
4. 创建 Cloudflare Quick Tunnel；
5. 生成 Join Code / GM Secret；
6. 启动同一个 `server.mjs`；
7. 等待 Server READY 并确认 `publicMode=true`；
8. 在当前窗口打印 Local / Network / Public 地址；
9. 打开 Public URL。

Internet 模式已经同时提供本机和局域网访问，所以**不要再启动第二个 Local Server**。

普通 Player 首次加入通常只需要：

```text
Public URL + Join Code
```

已有 User 在新的 Quick Tunnel 地址恢复身份时：

```text
Public URL + Join Code + Player Key
```

GM Secret 仅供 GM 使用。

---

## 4. 为什么现在只有一个 BAT

V1.5.2 之前启动层曾同时存在：

```text
start-rpgmap.bat
start-rpgmap-internet.bat
setup-cloudflared.bat
run-rpgmap-public-server.bat
local-launcher.mjs
internet-launcher.mjs
launcher-guard.mjs
```

这些文件把“用户入口”“安装辅助”“Server 参数”和“端口保护”分散成多条链路，容易让 Local 与 Internet 互相抢占 `30000`。

V1.5.3 收口为：

```text
start-rpgmap.bat
        ↓
launcher.mjs
   ├─ local
   └─ internet
        ↓
server.mjs
```

端口检查、READY 等待、浏览器打开、cloudflared 检测与 Public 参数都只有一个实现。

---

## 5. 端口冲突

Local / LAN 与 Internet / Public 都是**同一个 RPGmap Server 的两种模式**，默认都使用：

```text
PORT=30000
```

如果端口已有 RPGmap，Launcher 会识别它当前是：

- Local / LAN；或
- Internet / Public。

如果端口属于其他程序，也会明确报告。

遇到冲突时关闭旧 Server 窗口即可，不要同时运行两个模式。

---

## 6. Player User / Player Key

每个 World 自己维护持久 Player User：

```text
Connection Session
        ↓
Persistent Player User
        ↓
Default Actor + Actor Ownership
```

Player 第一次加入后可以由 GM 批准并绑定默认 Actor。Server 会生成 Player Key；Quick Tunnel 更换域名后，Player 可使用 Player Key 恢复原 User。

Server 只保存凭证哈希，不保存明文 Player Key。

---

## 7. Actor Ownership

| 权限 | 含义 |
| --- | --- |
| `NONE` | 没有控制权 |
| `OBSERVER` | 可查看，不允许修改 Actor |
| `OWNER` | 可以操控该 Actor |

默认角色必须是 OWNER。GM 对全部 Actor 隐式拥有完整权限。

---

## 8. Combat Turn Lock

Combat active 后，Player 只能修改：

```text
当前 Turn 对应 Actor
        +
自己拥有 OWNER 权限
```

GM 可以管理 Combatant、Initiative、Round、Turn 与战斗开始 / 结束。

权限同时经过 Client preflight 与 Server authoritative validation。

---

## 9. World / User 保存位置

```text
map/world.json
map/users.json
map/uploads/
map/backups/
```

`users.json` 不属于普通 World Snapshot，Player 不能通过 `world.push` 修改自己的 Ownership。

旧测试目录 `data/worlds/default/` 仍可在首次启动时自动迁移到 `map/`，旧文件保留。

---

## 10. 快速验收

### Local / LAN

1. 双击 `start-rpgmap.bat`。
2. 选择 `1`。
3. 等待窗口出现 READY 后浏览器再打开。
4. 本机访问正常。
5. 同 LAN 设备通过 `Network` 地址加入。

### Internet

1. 关闭 Local Server。
2. 再次双击 `start-rpgmap.bat`。
3. 选择 `2`。
4. 等待 Public URL / Join Code 出现。
5. 用手机 4G/5G 验证 Public URL。
6. LAN 设备仍可使用同一窗口的 Network 地址。

### 冲突保护

在一个模式已经运行时再次启动 `start-rpgmap.bat` 并选择另一模式，应该立即看到端口占用说明，而不是出现一直加载的网页。

---

## 11. 高级直接启动

可以跳过菜单：

```text
start-rpgmap.bat local
start-rpgmap.bat internet
```

Quick Tunnel 仍是临时公网入口。需要固定域名和长期部署时，再迁移 Named Tunnel / 自有域名。
