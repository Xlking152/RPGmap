# 规则包迁移检查清单

## 文档用途

本文记录 PR #13（`refactor/ruleset-v1`）的规则包迁移边界、兼容决定、已完成检查点和下一阶段验收标准。后续任务应先阅读本文，再基于 PR 当前 HEAD 继续，避免重新分析完整历史。

## 架构边界

### Core

- 提供稳定的通用 Actor 外壳、通用文档生命周期、权限、Actor/Token 定位、Synthetic Actor Delta 持久化、Effect 实例、状态层数、启用状态、属性变更和 capability 聚合。
- 只通过 Ruleset Contract 调用 Actor 默认值、迁移、规范化、验证、派生、属性路径、运行时操作、生命值、伤害、治疗、状态派生和展示逻辑。
- 不保存 Infinite Horror 专用状态 ID、B/L/A 字段名、伤势升级/治疗算法、默认伤害类型或死亡/昏迷阈值。

### Ruleset

- 持久化 ID 保持 `infinite-horror`。
- `RulesetV1.actor` 负责规则专用 `system` 默认数据、导入、旧存档迁移、规范化、验证、派生、属性路径、运行时操作，以及 Token/角色卡展示描述。
- `RulesetV1.health` 负责 simple HP、wound-track、B/L/A 伤势升级与治疗、死亡/昏迷判断、格式化、默认伤害类型、运行时操作解释和展示结构。
- `RulesetV1.statuses` 负责内置状态定义和基于 Actor/context 的派生状态。
- 规则包提供角色卡、Token 血条和聊天表单需要的模式、类型、摘要、状态、条段与编辑字段。

### World

- 拥有活动 Ruleset 引用、Actors 和 `statusDefinitions`。
- 新建或迁移旧存档时，以活动 Ruleset 的内置定义为权威刷新内置状态，同时保留用户自定义状态。
- `World.statusDefinitions` 是客户端与 Local/LAN Server 共同读取的状态定义来源。

### Scene

- 拥有地图包引用和 Tokens，不拥有规则算法或 Actor 的权威业务数据。
- Scene 内的 Synthetic Actor 只保存相对基础 Actor 的 Delta。

### Actor

- 通用外壳固定为 `id`、`name`、`system`、`effects`、`notes`、`createdAt`、`updatedAt`；规则专用角色数据全部位于 `system`。
- 旧顶层 `forms`、`currentFormId` 和 `runtime` 由 Infinite Horror 的迁移入口无损收进 `system`；已有 health runtime、B/L/A、形态、自定义资源和不良状态数据继续兼容。
- Core 消费者只读取通用 Actor/Ruleset 的 derive、presentation、attribute path 和 operation 输出。

### Token

- 通过 Actor 引用或 Synthetic Actor Delta 取得运行时数据。
- 血条、状态与交互能力由通用 Core 管线和活动 Ruleset 的 presentation/derive 输出驱动，不保存 Infinite Horror 算法。

## 持久化与兼容决定

- `world.ruleset.id` 保持 `infinite-horror`，不更改现有存档身份。
- 继续读取现有 Actor health runtime 和旧 B/L/A 数据形状；迁移不得丢失角色、Token、伤势、状态或自定义状态定义。
- 旧 Actor 顶层规则字段在读取时迁入 `actor.system`；旧 Synthetic Actor 的顶层 Delta 会转换为相对规范化 Base Actor 的 `system` Delta，基础 Actor 与同源 Token 不受实例覆盖影响。
- Effect 的规范属性路径使用 `system.resources.<id>.current|max` 和 `system.attributes.<id>`；Infinite Horror 仍兼容读取旧的无 `system.` 路径。
- Ruleset 内置状态会按当前规则包版本刷新；自定义状态按 ID 保留。
- 持久化 World 仅接受 schema 2；Ruleset ID 和版本必须精确匹配已注册规则包，不做静默降级或回退。
- 新 World 只在创建边界选择默认 Ruleset；已有 World、服务器 bootstrap 与认证后快照都以持久化 Ruleset 引用为权威。
- 通用操作协议版本为 1，不改变 World schema 或 Save 格式；服务器继续复用现有 `recentStatusOperations` 持久化字段保存有界 operation ID 记录，避免引入存档迁移。
- 普通多人提交只传播 operation patch；完整 World 快照仍用于首次认证/初始化、显式导入、幂等恢复和 revision gap 恢复。
- 浏览器、离线 WorldSystem、源码服务器与 packaged server 使用同一个 World operation reducer 实现；部署目录中的模块仅为源码服务器兼容 re-export。
- 服务器的状态权限与 capability 判定只依赖 World 中已持久化的状态定义和 Effect。基于生命值的派生状态由活动 Ruleset 在通用派生管线中生成；后续若需要服务器权威执行派生规则，应通过通用 Ruleset 运行边界实现，不能把 Infinite Horror 常量写回服务器 Core。
- 各架构迁移检查点期间应用版本保持 `1.7.0`；全部验收通过后的最终发行只提升应用版本到 `2.0.0`，不改变 World、operation 或 Ruleset 数据版本。
- 除中文界面文案和 `.md` 文档外，新增代码文件、变量、接口与测试名称使用英文。
